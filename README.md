# Sadi Portfolio
React + Vite + three.js. Black theme.

## Update content
Edit `src/data.js` only (add an achievement, role, project, badge). Push to `main`.

## Run locally
npm install && npm run dev

## Host on GitHub Pages
1. Create a repo (name it `5S4D1.github.io` for the root URL, or any name).
2. Push this folder to branch `main`.
3. Repo Settings > Pages > Source: **GitHub Actions**.
4. Every push redeploys automatically.
